> Governance standards and architectural conventions for monolithic software systems.

**Author:** [Jesus Ariel Gonzalez Bonilla](https://github.com/jesusarielgb-works)

## Overview

Defines governance standards for teams building monolithic applications: project structure,
layered architecture, database conventions, testing strategy, and deployment.

Companion: [microservices-governance-framework](https://github.com/code-corhuila/microservices-governance-framework)
(part of [jesusarielgb-works](https://github.com/jesusarielgb-works))
